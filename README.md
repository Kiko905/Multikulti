# Multikulti

Mobilná hra pre iOS a Android v Unity, orientácia na šírku.

## Pravidlá vetvenia
- `main` je vždy funkčná verzia. Priamo do nej necommitujeme.
- Každá úloha z Jiry má vlastnú vetvu podľa kľúča, napr. `SCRUM-90-parametre`.
- Do `main` sa zlučuje cez Pull Request, ktorý schváli aspoň jeden ďalší člen tímu.
- Commit začína kľúčom úlohy, napr. `SCRUM-90 Pridaný konfiguračný súbor`.
- Pred Pull Requestom si stiahni najnovší `main` a over, že sa projekt otvorí bez chýb.
- Na jednej scéne robí naraz len jeden človek.
